# 実装方式・コスト・品質の比較検証

目的: **iPhone で会議を録音しながら、直前〜数分前の発言を見返せるようにする**。費用はできるだけ抑える。

> 調査日: 2026-11-07。価格は各社の公開情報や第三者のまとめを参照した値で、変わることがあります。
> この開発環境からは OpenAI・Soniox などの API に接続できなかったため、**実音声での精度比較は同梱の
> 比較ページ(`bench.html`)を使って iPhone 上で行う前提**です(手順は最後に記載)。

### ChatGPT Pro の扱い
- **ChatGPT の画面(録音モードなど)は、リアルタイムで流れる文字起こしを見る用途には向きません**。
- ただし 2026年10月下旬から、**ChatGPT Pro/Business の加入者は毎月 API クレジットを受け取れる**ようになりました(ChatGPT の Settings → Billing → API credits から申請。繰り越しなし。ChatGPT と API の請求は別のまま)。
  → **C(OpenAI)の費用は、このクレジットの範囲内なら実質0円**です。1日1時間の会議を月20日行っても約$3.6(mini)/約$7.2(4o)で、クレジットの範囲に十分収まります。
- 要約機能(「🧠 要約」)も同じ API キーで動きます。1回あたり0.1円前後です。

## 2. 用途「直前の内容が飛ばないように」での評価

この用途で大事な点は次の3つです。
1. **数十秒〜数分前を素早く探せる**: 精度よりも「キーワードが拾えているか」が重要。
2. **止まらないこと**: 会議中に認識が止まると致命的。
3. **聞き直せること**: 文字起こしが怪しいときに音声で確かめたい。

| 観点 | B 内蔵(無料) | C OpenAI | D Soniox |
|------|-----------|----------|----------|
| 直前(〜10秒)の追従 | ◎ 即時 | △ 10〜25秒遅れ | ◎ 1〜2秒 |
| 数分前の振り返り | ○ | ◎ 文章として読みやすい | ◎ |
| 安定性 | △ iOSでは勝手に止まる・確定しない癖がある(自動再起動と2.5秒後の強制確定で対処) | ◎ 区間ごとに再送(最大3回) | ○ 通信が切れると止まる |
| 音声の聞き直し | ✗(マイクを内蔵認識が占有するため) | ◎ 直近10分(設定で変更可) | ◎ |
| 話者分離 | ✗ | ✗ | ○(オプション) |
| 費用/時 | 0円 | 約27円(Proのクレジットで実質0円) | 約18〜27円 |

### 結論(推奨)
1. **普段使い → C: OpenAI gpt-4o-mini-transcribe(既定)**
   ChatGPT Pro の API クレジットで実質無料。精度が高く、10〜20秒遅れでも「数分前を見返す」用途には十分です。聞き直しと要約も使えます。
2. **直前の一言まで即座に見たい場合 → D: Soniox**
   遅延1〜2秒、1時間20円前後。別途アカウントとチャージが必要です。
3. **完全無料にしたい/APIキーを用意したくない場合 → B: 内蔵認識**、または **A: ボイスメモ**
   ボイスメモは文字起こしと録音の両方が残り、無料の選択肢としては最も安定しています。ただし「◀1分」のような巻き戻しボタンや要約機能はありません。
4. **将来の選択肢 → F: ネイティブアプリ**
   画面を消しても録音を続けたい(バックグラウンド録音)場合や、完全無料かつ高品質を目指す場合に。Mac と Xcode が必要です。

## 3. 本アプリの既知の制約(Web アプリであることによるもの)
- **iPhoneの画面を消したり、他のアプリへ切り替えたりすると、マイクが止まる場合があります**。Wake Lock で画面のスリープは防いでいますが、会議中はアプリを前面に出しておいてください(ネイティブアプリならこの制約はありません)。
- OpenAI 方式は前の区間の末尾をヒントとして渡していますが、区間をまたいだ単語が分断されることがあります。
- 内蔵認識(B)の精度・挙動は iOS のバージョンによって変わります。

## 4. 実際の精度を検証する手順(bench.html)
1. 実際の会議(または会議に近い音声)を iPhone のボイスメモで3〜5分録音し、「ファイルに保存」します。
2. 一部(1〜2分でも可)を人手で直して、正解テキストを作ります。
3. アプリの「⚙︎設定」でAPIキーを入れ、「方式の比較検証ページへ」を開きます。
4. 音声ファイルと正解テキストを入れ、「比較を実行」を押します。OpenAI 3モデルと Soniox が、**ライブ時と同じ区切り方**で処理されます。
5. 内蔵認識とボイスメモは、同じ音声を別の端末から再生して認識させ、その結果を「手入力の結果」に貼り付けます。
6. 表に **CER(文字誤り率)・処理時間・1区切りあたりの遅延・1時間換算の費用** が並びます。結果はJSONで保存できます。

CER の目安: 会議音声では 5〜10% ならかなり読みやすく、15〜20% でも「何の話だったか」を思い出す用途には十分なことが多いです。
